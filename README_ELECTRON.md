üneyyurt Kurumsi Arazi Suyu Takip Uygulaması - Electron Edition

Bu proje, Fyne (Go) altyapısından Electron + React altyapısına taşınmıştır.
Bu sayede daha modern, performanslı ve hatasız bir kullanıcı deneyimi sunulmaktadır.

## Nasıl Çalıştırılır?

1. **Geliştirme Modu:**

   ```bash
   pnpm run dev
   ```

2. **Paketleme (Kurulum EXE Oluşturma):**
   ```bash
   pnpm run package
   ```

## Özellikler

- **Modern UI:** Tailwind CSS ve Framer Motion ile akışkan arayüz.
- **SQLite:** Better-SQLite3 ile hızlı veri depolama.
- **Excel:** `xlsx` kütüphanesi ile doğrudan veri aktarımı.
- **Türkçe Karakter Desteği:** Tamamen UTF-8 uyumlu.
